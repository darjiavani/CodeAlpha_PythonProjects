# 🚀 CodeAlpha Python Programming Internship Projects

This repository contains the projects completed as part of the **CodeAlpha Python Programming Internship**.

## 📌 Projects Included

### 🎯 1. Hangman Game

A GUI-based Hangman Game developed using Python and Tkinter.

#### Features

* Random word generation
* User-friendly GUI
* Interactive gameplay
* Score tracking

---

### 📈 2. Stock Portfolio Tracker

A GUI application for tracking stock investments and calculating portfolio value.

#### Features

* Add stock details
* Calculate total investment
* Portfolio management
* CSV file support

---

### 🤖 3. Basic ChatBot

A simple rule-based chatbot developed using Python Tkinter.

#### Features

* Interactive GUI
* Predefined responses
* User-friendly interface
* Basic conversational functionality

---

## 🛠 Technologies Used

* Python
* Tkinter
* CSV File Handling
* Object-Oriented Programming (OOP)
